# ابدأ هون — أيجنت جديد بدون سياق سابق

آخر توجيه: **2026-10-16**. المستخدم أثنى على فيلم إسكوبار الكامل وسمّى اتجاهه **«وثائقي بحت»**. ما طلب يجعل كل الفيديوهات بنفس الستايل؛ طلب عائلة ستايلات مفهومة وقابلة للتنفيذ بمحرّك مشترك.

**آخر إنتاج جديد:** `engine/projects/black_hole/` — **What If You Fell Into a Black Hole?**،2:04.58،1080p،إنكليزي،نفس هوية voice-02 المعتمدة. اكتمل تصحيح المشاهد والنص ومراجعة كل29صفحة نهائية وثمانية فريمات أصلية. الفيلم مرفوع ومقارنته بالحجم/MD5 نجحت؛ توثيق الاستعادة والتسليم في البروفايل. بانتظار رأي المستخدم، مو معتمد تلقائياً. نموذج الزحمة السابق أعجب المستخدم تنفيذه ورفض فكرته؛ إسكوبار المعتمد دون تعديل.

## ترتيب القراءة الإلزامي

1. `engine/STYLE_GUIDE.md` — الفهم الإخراجي والفروق والأخطاء الممنوعة ومثال البورد المتصل.
2. `engine/STYLE_REGISTRY.json` — الأسماء العربية/المعرّفات، مصدر الاعتماد، وما هو اتجاه مطلوب فقط.
3. `engine/PRODUCTION_POLICY.json` + `engine/DOCUMENTARY_MATERIALS_AND_IDEAS.md` — قواعد اللغة/المواد/الأداء؛ **الحقيقي أولاً في الفيلم الوثائقي لا يعني فرض الأرشيف على الشرحي البحت**.
4. `engine/EDITORIAL_REVIEW_PROTOCOL.md` — مراجعة فعلية للترميز، لا checklist فقط.
5. `engine/ENGINES.json` + `engine/AGENT_BRIEF.md` — الأدوات وحدودها الفعلية. اقتراح المخرج الآلي ليس بديلاً عن فهم المادة أو ضماناً فنياً.
6. `engine/HANDOFF_STATE.json` + `HANDOFF.md` — الحالة الأحدث والروابط؛ الدراسات القديمة ليست كلها موافقات فنية.

## الاستدعاء السريع

```bash
# من جذر المستودع، بلا تثبيت مكتبات رندر:
python3 youtube_documentary/tools/style_contract.py list
python3 youtube_documentary/tools/style_contract.py init \
  --style 'وثائقي بحت' --project youtube_documentary/engine/projects/NEW_FILM
# سجّل قرار المستخدم الحقيقي في selection_evidence وألّف MATERIALS.json أولاً:
python3 youtube_documentary/tools/style_contract.py check \
  --project youtube_documentary/engine/projects/NEW_FILM
```

`init` يكتب مسودة فقط، ولا يستبدل ملفاً موجوداً. العقد وحده لا يجعل الفيلم جاهزاً. الفحص يتحقق من تطابق **تصريحات** المادة والستايل، لا من البكسلات أو جودة المونتاج. المشاهد الشرحية تحتاج `scene_design` بفهم المشهد، لا عنوان «3D» فقط. للغة والمصدر والحقائق والسماع والمراجعة النهائية فحوصها المنفصلة.

## الثابت والمتغير

- **ثابت:** المعنى قبل الزينة؛ لا PowerPoint/سلايدات آلية؛ لا حركة أو2D عالفاضي؛ لا ادعاء3D بظلّ؛ أصوات ومصادر صادقة؛ إنكليزي داخل الفيديو؛ مراجعة فعلية قبل التسليم.
- **متغيّر حسب الفيلم:** مقدار الأرشيف، المشاهد المؤلفة، الكرة الأرضية، البورد، الكلمات، الكاميرا، الريثم، الطول. لا نسب ولاWPM ولا قالب انتقالات مفروضة لكل فيديو.
- **معتمد فعلاً:** اتجاه «وثائقي بحت» بناءً على ثناء المستخدم على الفيلم الكامل الحالي. **مطلوب وليس معتمداً كفيلم نهائي بعد:** وثائقي مع شرح، شرحي بحت، شرحي مع أرشيف قليل.
- لا تعِد الرندر ولا تولّد صوتاً أو ديمو جديداً لمجرد حفظ الستايل. المطلوب بهالخطوة هو حفظ نظام الفهم والتسليم للأيجنت التالي.

الروابط والـhash للفيلم المرجعي ضمن الفهرس. وجود ثلاث خرائط مصرّح عنها وصورة2.5D فيه مو إذناً لتوسيع «وثائقي بحت» تلقائياً بمشاهد مختلقة، ولا يلغي اختيار المستخدم لأساسه الأرشيفي الحقيقي.
