# 06 · قائمة فحص الجودة — v2 (قبل أي تسليم)

> علّم `[x]` بعد الفحص الفعلي فقط. بلا علامات اعتماد بالافتراض.
> المستجدات في v2 معلّمة بـ ➕

## 1. القصة والحقائق
- [ ] النص النهائي محفوظ بإصدار واضح.
- [ ] الأسماء والتواريخ والأرقام مدققة مقابل المصادر.
- [ ] الادعاءات المتنازع عليها موسومة/منسوبة بدقة.
- [ ] الصورة لا توحي بأنها دليل على شيء لا تثبته.
- [ ] لا جملة أضيفت أو حُذفت خارج النطاق الموافق عليه.

## 2. الحقوق والمصادر
- [ ] لكل صورة/فيديو/صوت مصدر ورابط وترخيص موثق في سجل الحقوق.
- [ ] الإسناد المطلوب موجود في الملف ويظهر على الشاشة حين يلزم.
- [ ] المواد المعاصرة موسومة كصور حالية وليست تاريخية.
- [ ] كل إعادة بناء AI موسومة بوضوح ولا تبدو أرشيفاً.
- [ ] لم تُستخدم مادة متنازع على ترخيصها (تذكير: صورة الشرطة المرفوضة).
- [ ] لا ستوك عام غير مرتبط بالقصة.
- [ ] لا تكرار لأي صورة/مادة في لقطات منفصلة — أو لقطة واحدة مستمرة فعلاً.

## 3. الصورة والمونتاج
- [ ] ➕ ما في أي مشهد يوصف بـ"سلايد/بطاقة/تمبلت" أو إحساس PowerPoint.
- [ ] ➕ لا تكرار بين الكابشن المحروق والنص الحركي لنفس الجملة (طبقة نص واحدة).
- [ ] ➕ كل نص مربوط بكلمة منطوقة، وما بينطر على الشاشة بعد الجملة.
- [ ] ➕ السكتات المقصودة موجودة، وخلالها الصورة تبقى حيّة (ما في تجميد).
- [ ] ➕ البورستات إيقاعها صحيح: بورست قصير ثم لقطة تريّح (ما في بورست متواصل ممِل).
- [ ] ➕ بلا كت داخل المشهد الواحد (نمط اللوح/الكرة خاصة).
- [ ] ➕ الكليبات المتحركة بجرعة ومربوطة بالجملة (≤ ~20–25% من المدة، بلا حشو).
- [ ] كل خريطة توضح المكان/المسار مع تأهيل "تقريبي/توضيحي" عند اللزوم.
- [ ] الحركة والنص الحركي يخدمان الكلام (لا كل جملة = عنوان).
- [ ] لا زووم صورة ثابتة كتعويض عن غياب مادة.
- [ ] لا لقطة مطوّلة بلا سبب؛ لا قفزات حركة غير مقصودة.
- [ ] النصوص مقروءة على الهاتف ولا تحجب الوجوه/الوثائق.
- [ ] ➕ كل رقم/رسم بياني يظهر معه المصدر ونوعه (إحصاء/تقدير/ادعاء).

## 4. الصوت والكابشنات
- [ ] التعليق الصوتي هو النسخة المعتمدة (أو أُعيدت الموافقة عليه).
- [ ] الكلمات واضحة ومزامنة مع الصورة.
- [ ] لا تداخل بين الفصول أو تراكب كلام غير مقصود.
- [ ] ➕ صفر موسيقى خلفية.
- [ ] ➕ SFX قليلة (حدود عملية: ≤ ~6 في الدقيقة) ومربوطة بالحركة، وتراخيصها موثقة.
- [ ] SRT موجود ومختبَر على الفيديو (التوقيت سليم).
- [ ] النسخة المحروقة/ASS (إن طُلبت) سليمة وغير مقصوصة.

## 5. إخراج الملف
- [ ] اسم الملف بإصدار جديد ولا يستبدل نسخة سابقة.
- [ ] الحاوية/الكودك/الدقة/الأبعاد/FPS مطابقة (افتراضي: MP4، H.264، 1920×1080، 30fps).
- [ ] المدة النهائية مطابقة للسرد والكابشنات.
- [ ] مسار فيديو وصوت صالحان (ستيريو عند الحاجة).
- [ ] فُكّ ترميز الفيديو كاملاً (ffmpeg/ffprobe) بلا أخطاء.
- [ ] مشاهدة عينات: البداية، المنتصف، النهاية + مشهد من كل فصل.
- [ ] مراجعة مشاهد الأرقام والأسماء والحوادث والمواد الحساسة.

## 6. التسليم والتواصل
- [ ] سجل المصادر/الترخيص + النوتة (Shot Spec) + manifest موجودة.
- [ ] SRT وملفات المشروع مرفقة حسب الاتفاق.
- [ ] رُفع الملف للمجلد الصحيح وتحققنا من ظهوره فعلاً.
- [ ] لم تتغير صلاحيات Drive إلى عامة دون إذن.
- [ ] أُرسلت خلاصة قصيرة بالمواصفات والروابط والقيود.
- [ ] أثناء الرندر الطويل وصلت تحديثات موجزة بدل ترك المستخدم منتظراً.
