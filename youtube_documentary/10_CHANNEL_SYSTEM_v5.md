# 10 · الأنظمة كأساس للقناة (v6) — مشهد = ملف JSON

> كل شي صار **أساس لأي فيديو** — بنبني قناة، مش فيديو واحد.
> الطريقة: **محركات ثابتة + ملف وصف لكل مشهد**. مشهد جديد = ملف JSON + أمر واحد.

## أمر واحد لكل مشهد

```bash
python3 tools/build_scene.py config/<scene>.json <اختياري: اسم الملف> <اختياري: ثانية البوستر>
```
ثلاث مراحل تلقائية: **إطارات → صوت → دمج MP4**. كله محلي، بلا إنترنت، بلا واترمارك.

## المحركات (v6)

| المحرك | الملف | يعمل شو | الجديد |
|---|---|---|---|
| **board** | `tools/engines/board_engine.html` | اللوح: صورة بلا إطار → اسم + توقيع → سيلويت + خيط نور → BUT WHY | **ضبط تلقائي للفريم (stage-fit):** يقيس الصورة+الاسم+التوقيع+السطر ويصغّرها حتى **ما ينقص أي شي أبداً**؛ و«؟» الحمرا صارت **تحت BUT WHY** |
| **geo** | `tools/engines/geo_engine.html` | كرة أرضية حقيقية (NASA 4096): انبثاق نقطة → مسار great-circle → وصول + تسميات | **كاميرا سينمائية:** `cam` بالملف — **زوم على لحظة الانبثاق**، **ملاحقة رأس السهم** بالزوم وهو يطير، **هبوط على الوجهة** واسمها ينبثق |
| **story** | `tools/engines/story_engine.html` | **بلا لوح:** لقطات أحداث — `establish` / `walk` / `counter` / `walkaway` | **جديد كلياً**: سيلويت يمشي بظل تلامس + عدّاد مبلغ ينفجر (فلاش/اهتزاز/موجة/خط يُرسم) + كابتن وقتي + وهوغ شمس |

## قواعد الفيديو (أساس لكل حلقة)

1. **لا فريمات ولا براويز** — الصورة تنزل عالسطح كما هي، كاملة.
2. **النصوص كلها داخل الفريم** — المحرك يقيس ويضبط تلقائياً (بعد كل خط/صورة/توقيع).
3. **الاسم يُكتب تحت الصورة** بحبر فاتح، والتوقيع الحقيقي يُرسم تحته.
4. **السيلويت للمجهولين** — ما نولّد ملامح شخص حقيقي إلا **بمرجع حقيقي**. الأشياء العامة (مبنى، قاعة، مدينة) توليد حر.
5. **صفر موسيقى** — مؤثرات **نظيفة، بلا صدى** (رجّعنا الريفيرب من 0.30 إلى 0.10–0.12 وفكّينا الديكاي 2.6→1.4).
6. **كل النص مونتاج** — بلا كابشنات، إنجليزي على الشاشة.
7. **الكروت الفارغة بعيدة** فلا يدخل بكادر غيرها.

## SFX المتوفّرة (`tools/synth_sfx_cine.py`)

`whoosh` · `whooshUp` · `impact` · `brush` · `swell` · `note` · `riser` · **`step` (خطوة مشي جديدة قافية الجديدة)** — تُوصَف داخل `audio` في إعداد المشهد:

```json
{ "t": 6.35, "sfx": "impact", "gain": 0.30, "f0": 120, "f1": 42 }
{ "reverb": { "mix": 0.10, "decay": 1.4 } }
```

## أدوات مساعدة

- `tools/qa_frame.py` — **قياس ضبط**: يفتح المحرك، يقف على ثواني محددة، ويفحص إن كان أي عنصر خارج الفريم. (استخدمناه لنكشف قصّ الصورة والسطر.)
- `tools/setup_env.sh` — يجهّز البيئة بعد أي تصفير للورك سبيس.
