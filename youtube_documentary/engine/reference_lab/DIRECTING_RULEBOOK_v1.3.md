# DIRECTING RULEBOOK v1.3 — من السكربت للمشهد (قواعد عامة، مو قوالب)
> الهدف: تعطيني **سكربت بس** ← أنا بقسّمو لـ beats، بصنّف كل جملة، وبطلّع المشهد والانتقال والنص والصوت بدون ما تشرحلي.
> كل قاعدة إلها **مصدر** (فيديو + توقيت شفتو بعيني). القواعد بتتحدّث بعد كل فيديو بندرسو.
> نسخة: **v1.2** — القسم 0–14 من v1.1 (مبنية على Vaping/MagnatesMedia، 2fps كامل).
> **جديد v1.2**: الأقسام 15–19 من دراسة **WW2 Part 1 / OverSimplified كاملة (2fps، 28 صفحة، 0:00–13:45، فحص تغطية PASS)**.
> الفرق هيك: v1.1 = الأسلوب السينمائي (MagnatesMedia) · v1.2 = الأسلوب المرسوم (OverSimplified) + قواعد مشتركة كانت مخفية.
> الجاي: PayPal، Crypto، Apple، AI، Saudi، WW2 P2، Dubai.

## 0. خوارزمية الإخراج (كل مرة بتعطيني سكربت)
1. **قسّم السكربت لـ beats**: beat = جملة أو نص جملة إلها فكرة وحدة. (Vaping بالمتوسط beat = 2–6 ث.)
2. **صنّف كل beat** حسب نوعو (الجدول 1) ← هيك بيطلع **نوع المشهد**.
3. **حدّد طاقة الـ beat** (0–3): 0 = سياق هادي، 1 = سرد، 2 = كشف أو رقم، 3 = صدمة أو ذروة.
4. **اختار الانتقال** حسب الفرق بالطاقة والفرق بالمزاج اللوني (الجدول 3).
5. **قرّر النص يلي على الشاشة**: بس الكلمات يلي لازم «تنحفر» بالراس (رقم، سنة، اسم، اقتباس، مفارقة). باقي التعليق بيضل صوت بس.
6. **وزّع الألوان**: كل فصل إلو حرارة لونية بتتغيّر مع القصة (الجدول 4).
7. **ركّب الإيقاع**: الافتتاحية والذروات بيتسارعوا، والسرد بيتنفّس، وقبل كل فصل أسود وصمت.
8. **الصوت تحت الصورة**: ضربة (hit) مع القطع الحاد، صوت هوا (whoosh) مع مسحة الدخان، riser قبل الكشف، **صمت حقيقي** بالفواصل. المؤثرات أوطى من الموسيقى بـ 6–8 dB، والصوت بيضل يقود.

## 2. أنواع اللقطات (بنحطها بالمحرّك)
- **Tableau**: صورة سينمائية وحدة + دفشة أو انزلاق بطيء (2–6 ث) + ضباب متحرك. هيدي اللقطة الأساسية لأغلب السرد.
- **Cutout parallax**: أشخاص مقصوصين قدام وخلفية ورا، والطبقات بتتحرّك بسرعات مختلفة.
- **Hero object**: غرض بالنص بفراغ ملوّن، بيلف أو بيطوف، وحواليه جزيئات.
- **Data**: رسم بياني أو خريطة أو عدّاد أو checklist، دايماً على خلفية غامقة فيها شبكة أو ملمس.
- **Evidence card**: لقطة شاشة لمقال أو تغريدة أو وثيقة، بتطوف أو مقصوصة من قريب.
- **Type-only**: بطاقة فصل، أو توقيع القناة، أو العنوان على دخان.

## 3. قواعد الانتقال
| الحالة | الانتقال |
|---|---|
| نفس الفكرة، نفس اللون | حركة كاميرا متواصلة أو تبديل جوّا اللقطة، **بدون قطع** |
| تغيّر الموضوع، نفس الطاقة | مسحة دخان بلون الوجهة (أبيض أو أحمر أو سماوي) |
| طاقة بتطلع (كشف) | الشاشة بتبيضّ أو flash، أو دخان أبيض بيعبّي الشاشة |
| طاقة بتنزل لخطر | دخان أحمر بيجي من طرف الشاشة |
| تسارع الذروة | قطعات حادة كل 0.5–0.9 ث |
| نهاية فصل | ← أسود (1.5–2.5 ث) **+ صمت** ← بطاقة فصل ← أسود ← ختم سنة |
| قبل العنوان الرئيسي | ضربة ← أسود |

> قياس: Vaping فيه 109 قطع حاد بس بـ27 دقيقة، والباقي كلو انتقالات ناعمة وحركة متواصلة.

## 4. الألوان وشو بتعني
- **سماوي (teal/cyan)**: طموح، تكنولوجيا، مصاري، بداية الحلم.
- **أحمر مشبّع**: خطر، إدمان، عنف، سقوط، اتهام.
- **برتقالي أو ذهبي**: نجاح شركات، سلطة، صفقات.
- **أبيض أو ضو قوي**: إعلانات، «جنة» المنتج، كشف.
- القصة بتنتقل من السماوي للأحمر كل ما تقرب من السقوط. **الألوان بتحكي القصة حتى لو بلا صوت.**

## 5. قواعد النص على الشاشة
- خط عريض ومكثّف (Bebas أو Oswald)، أبيض، بالنص، ظل ناعم. وكلمة وحدة ملوّنة للتشديد.
- **حد أقصى 4–6 كلمات** بالشاشة الوحدة، والجملة الطويلة بتنقسم كتل.
- الأرقام والسنين: أكبر عنصر بالشاشة، بتدرّج أو بأبعاد ثلاثية، وبيمشي العدّاد.
- العنوان الرئيسي **هادي ومش ضخم** (رمادي، serif أو sans خفيف) على دخان غامق.
- **وقت كافي للقراية**: ~0.25 ث لكل كلمة + 0.5 ث. *(ملاحظتك بالامتحان الأول: الزوم كان قوي وما قدرت تقرا. القاعدة صارت: نص فيه أكتر من 4 كلمات = دفشة ≤10%، والعنوان كامل جوّا الكادر.)*

## 6. الإيقاع
- **الافتتاحية (0–35 ث)**: دليل إعلامي، بعدين جرعة سينمائية، بعدين اقتباس، بعدين رقم أو خريطة، والقطعات بتسرع، وبعدها ضربة وأسود.
- **بعدها**: توقيع القناة من الدخان، بعدين العنوان، بعدين أسود وصمت، وبعدين القصة بتبلش بمشهد واسع وحركة متواصلة.
- **السرد**: beat كل 2–6 ث، وكل 30–60 ث في «حدث بصري» (رمز، رقم، كشف) لحتى ما يملّ المشاهد.
- **الفصول** كل 2–4 دقايق (Vaping: 1:42، 3:50، 6:02، 9:16، 17:10، 21:46…).
- **فاصل الإعلان**: لغة بصرية مختلفة كلياً، وبيرجع ببطاقة فصل.

## 7. الصوت
- الموسيقى بتتغيّر مع كل فصل، ومستوى الصوت العام حوالي -18 LUFS.
- المؤثرات **تحت** الموسيقى بـ 6–8 dB *(ملاحظتك: المؤثرات كانت عالية، وهلأ نزلت)*.
- صمت **حقيقي** مع كل أسود.

## 8. Checklist قبل التسليم (ضد «PowerPoint»)
- [ ] ما في لقطة ثابتة 100% (دايماً في حركة، ولو 3%).
- [ ] كل نص بينقرا بالوقت يلي إلو، وما في نص طالع برا الكادر.
- [ ] العناصر الجغرافية بمكانها الصح (النقاط ع اليابسة، الخطوط من المدينة الصح).
- [ ] تغيّر لوني مع تغيّر المعنى.
- [ ] مؤثرات أوطى من الموسيقى، وصمت مع الأسود.
- [ ] ما في انتقالين ورا بعض من نفس النوع إلا إذا مقصود (تسارع).

## 11. نص وأرقام (إضافات)
- **عدّاد بلون المعنى:** أخضر = مصاري جاية، أحمر = خسارة (-34% ← -95%). العدّاد دايماً فوق غرض أو رسم، مش لحالو.
- **قفزة القيمة:** الرقم الجديد بيطلع فوق القديم بنفس المكان ($12.8B ← $38B).
- **السنة:** أرقام بتطير وتتجمّع / بتطلع من blur لوضوح / بالسما وبعدين tilt للمكان / ورا الغرض (النص بين الطبقات).
- **جملة الحسم:** ترجمة صفرا كلمة كلمة فوق ظلال حشد، و**الكلمة المفتاح بآخرها بتنعزل وبتكبر** (HAPPENED).
- **السخرية:** الكلمة المفتاح بين [قوسين] وبلون أحمر.
- **cliffhanger:** حروف حمرا ضخمة بتعبر بسرعة مع motion blur وبتنضغط لسطر، وبعدها أسود.
- **صفة الشخص:** كلمات بتتراكم جنبو. **اسم الشخص:** ضخم وأبيض، بيتكشف بقناع عضوي، وبعدين بيتبدّل لحكم («HORRIBLY WRONG») بنفس المكان.
- **أسماء مكوّنات/أعراض:** خطوط إشارة (callouts) مع أسماء صغيرة حوالين الغرض/الجسم.
- **الإحصاء:** أيقونات بتطلع بالعدد، والنسبة بلون مختلف (1 من 5 أحمر).

## 12. الأرشيف والدليل
- الأرشيف الحقيقي (أخبار، جلسات، صحف، فيديوهات شهادات) **بيضل نيّ**: كادر كامل، بدون تعديل، بس push صغير. القوة بإنو حقيقي.
- السوشال بيتعرض **جوّا UI المنصة** (Instagram، TikTok، تغريدة)، والفيديو العمودي جوّا إطار أسود.
- تعليم الدليل: دائرة حمرا مرسومة بالإيد حوالين التفصيل.
- الوثيقة الرسمية: شاشة CRT قديمة بالمشهد، أو ورقة مضوّية بين ظلّين.
- مقال صحفي: push لجوّاه + هايلايتر أحمر ع الجملة المفتاح؛ أو سطر واحد واضح والباقي blur.

## 13. البنية الكاملة للفيديو الطويل
1. **الافتتاحية (0–34 ث):** عناوين حقيقية ← أخبار ← تهديد ← اقتباس كلمة كلمة ← خريطة انتشار ← ضحايا حقيقيين ← العضو المتضرّر ← السلطة بتسأل. تقطيع متسارع.
2. **العنوان:** أسود ← «Presents» بالدخان ← عنوان رمادي صغير ← أسود 3 ث (صمت).
3. **ملخّص القصة (0:47–1:38):** الصعود (ظلال منتصرة، مونوليث) ← الانهيار (رسم -95%) ← السخرية ← المفارقة (لوغو بالسما) ← المؤسسين ← اللوغو كختم.
4. **الفصول:** أسود 2–2.5 ث ← «CHAPTER N: X» بينزلق مع motion blur فوق دخان بيتغيّر لونو ← أسود 2–2.5 ث. **نفس الشكل كل مرة** (ثبات = هوية).
5. **الإعلانات (راعي وترويج ذاتي):** معزولة بالأسود، وبلغة بصرية تانية كلياً (هوية الراعي) لحتى ما تخرب غريد القصة.
6. **الخاتمة:** خط زمني أحمر للتلخيص ← استعارة حرفية (خيوط دمى = سيطرة) ← سؤال بلاغي بخط أحمر كبير فوق الاستعارة ← flash أحمر كامل ← «THANK YOU FOR WATCHING» ← fade.

## 14. قواعد صغيرة متفرّقة (من 2fps)
- لقطة من فوق (top-down) لطاولة = تخطيط/تصميم.
- Shot/reverse: الشاشة ← الوجوه المضوّية منها.
- الشخص قدام شباك والمنظر ورا عم يتغيّر = حرية/سفر/وقت.
- fisheye + أشعة ضو = فرحة/نجاح مجنون.
- أبيض وأسود = ماضي، تأمّل، أو «من جهة».
- حشد ظلال مع انفجار نيون = «ملايين».
- جدار صور 3D = كثرة.
- الشعار بيتشطّب بضربات فرشاة بيضا.
- التناظر + دفشة لـblur = انتقال ناعم.
- العنصر الوسطي محاط بكروت المنتج يمين وشمال.
- الخطوات = كروت 3D + خط منقّط بيوصلن.
- الخيارات/الحيرة = أيقونات طايفة حوالين الراس.
