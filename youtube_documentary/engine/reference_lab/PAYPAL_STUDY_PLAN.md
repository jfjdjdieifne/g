## 3) شو ندوّر عليه بهاي المرة (PayPal مقابل Vaping — **نفس القناة**)

هدف الدراسة مو بس «نفهم الفيديو»، بل **نشوف التطوّر** بين 27 دقيقة و57 دقيقة:

| السؤال | ليش مهم |
|---|---|

| شو صار بالإيقاع على **مدى 57 دقيقة**؟ (قطع/دقيقة أول 10 دقايق مقابل النص) | عندنا قياس Vaping: 109 قطع/27د. الفرق بيحدد «قانون الإطالة» |
| بطاقات الفصول: نفس الشكل (أسود+صمت → نص يزحف ع دخان)؟ ونفس المدة؟ | يثبّت قاعدة الفصول أو يعدّلها |
| الفتحة: نفس بنية «دليل إعلامي → عنوان → كتل اقتباس → خريطة»؟ | لو تكرّرت = هيكل ثابت للقناة (rulebook staple) |
| كيف بيعالجوا **سبونسر + عرض ذاتي** (نفس معالجة Vaping: أسود + هوية مختلفة)؟ | قاعدة «عزل واضح» |
| الخاتمة: خط زمني أحمر → استعارة حرفية → سؤال كبير → فلاش → شكراً؟ | قاعدة الخاتمة |
| أدوات جديدة ما شفناها بـVaping (خرائط، واجهات UI، رسوم، مقارنات) | تقنيات جديدة تدخل `techniques.json` |
