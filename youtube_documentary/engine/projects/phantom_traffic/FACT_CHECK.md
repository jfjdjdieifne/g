# Factual scope / primary project documentation

Retrieved 2026-10-16: https://github.com/flow-project/flow/blob/master/docs/source/examples.rst via GitHub contents API. Exact retrieved body retained in RESEARCH_flow_examples.rst.

Read: “Stabilizing the Ring”, “Avoiding Capacity Drop”, and “Stabilizing On-Ramp Merge”. Flow describes the spontaneous travelling shockwave after Sugiyama (2008); the autonomous controller observes its own speed, leader speed and leading gap. Its merge example describes merging causing a decelerating shockwave. Its bottleneck section describes increasing inflow reducing outflow.

| Spoken explanation | Basis and limit |
|---|---|
| A jam need not have a fixed blockage | Spontaneously formed travelling shockwave on a ring, Flow documentation above. “Can”, not every unexplained jam. |
| Later responses can amplify a small brake | Standard delayed car-following mechanism illustrated here. Illustrative staggered responses are authored, not experimental reaction-time values. |
| Cars travel forward, wave backward; membership changes | Spatial wave-pattern explanation. Numeric direction verified in authored source test; not passed off as empirical observation. |
| Room permits smoother response | Leading gap/speed feedback motivates smooth response. An illustrative buffer, not universal safety advice or a claim that all jams can be removed by individual drivers. |
| Merges / heavy demand can still queue | Flow merge and capacity-drop examples. Crashes are explicitly an additional possible obstruction, not a claim about this scene. |
