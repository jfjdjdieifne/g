# اختبار تصميم v3 — خرائط متصلة، غير معتمد

## حكم المستخدم الملزم
v2 تطورت، لكنها نسخة خام لا ترقى إلى مستوى المراجع: الانبثاقات والمستطيلات والإكسسوارات تبدو Paint/PowerPoint. لا تكفي إزالة العيوب التقنية أو زيادة الملمس لإثبات الاحتراف. لا ننتقل إلى PayPal قبل مراجعة هذا الاختبار.

## نطاق هذه الجولة
اختبار 16 ثانية، 1920×1080 / 24fps، بلا تعليق صوتي. ليس إعادة إنتاج كامل ديمو v2 ذي 11 كرتاً، وليس وثائقياً نهائياً. يعزل مشكلة تصميم الخرائط وترابط الحركة. لا يختبر جودة الشخصيات أو الأرشيف أو التكوين ثلاثي الأبعاد. لا يُضاف ستايله إلى قائمة المحركات المعتمدة قبل موافقة المستخدم.

## دليل المرجع
أعيد فتح صفحة WW2 P2 رقم 5 كاملة، وأعيد فحص مقتطفات الصفحات 1 و9 و15. هذه إعادة مراجعة محددة، لا مشاهدة جديدة لكل الفيديو أو لكل الفريمات الأصلية.
- WW2 P2 @2:04–2:08: خريطة بحرية، بلد ملوّن ووحدة شحن فوق نفس المشهد.
- WW2 P2 @2:13.5–2:15: خط اتصال أصفر/برتقالي مع الحركة فوق الخريطة، لا واجهة شارات منفصلة.
- الكرت القائم `supply_line_draw` موثّق WW2 P2 @2:08.5؛ نافذة 2:13.5 توضح الخط في نفس التسلسل.
- الكرت القائم `map_inline_label` موثّق WW2 P1 @1:17.5. لم تُسترجع هذه النافذة في الجولة؛ نعتمد سجل المشاهدة السابق، لا ندّعي إعادة مشاهدتها.
- الكرت القائم `drawn_arrow_telegraph` موثّق WW2 P2 @3:23؛ خطوط التقارب الحالية تطبيق جديد، لا نسخ مسارات تاريخية.

## تصميم مقابل v2
- أزيلت شارات التسميات، الختم، عدادات الإحصاءات غير الموثقة، وانبثاقات البلوكات الكبيرة.
- أطلس 5760×4320 واحد، ملمس ثابت في إحداثيات العالم؛ لا ضوضاء أو jitter عشوائي يتبدل بين الفريمات.
- خطوط حدود حقيقية. عاد Brazil إلى الجغرافيا بعد تصحيح ISO `076`→`76`، لمنع ظهور البحر مكان الأرض.
- لون مميز لكولومبيا، النص العربي متصل مع fallback مجمّع للرموز الناقصة؛ لا تحريك/رجّة حرف حرف.
- التسميات بحجم شاشة ثابت لا تكبر مع الكاميرا. موضع ميديين يتغير بسلاسة لتجنب المسار والكابشن.
- لا يتم استدعاء مكتبة الحبر التجريبية: الشكل اليدوي ليس مرادفاً للاحتراف.

## حدود الحقيقة
كامل الاتصال والطرق الثلاثة رموز سردية للاختبار، لا مسارات تهريب/انتشار شرطة موثقة. التلوين الأحمر لكولومبيا تأكيد بصري، لا ادعاء سيطرة أو منطقة عمليات تغطي الدولة كلها. سنة 1993 إطار سردي؛ اتصال ميامي لا يُقدَّم كحدث محدد في هذه السنة. أزيلت ادعاءات 525/25 طن لأن هذا اختبار بصري بلا مصدر لهذه الأرقام.
الصوت من محرّك التوليد السابق، مع إعادة توقيت ست مؤثرات على الزوم والمسار والختام، وتخفيضها تحت الخلفية ثم خفض الماستر. هذه خلفية drone اصطناعية، لا موسيقى أوركسترالية احترافية. جودة الصوت الفنية غير معتمدة.

## بوابة قبول
هذا اختبار غير معتمد حتى لو اجتاز الاختبارات التقنية. يلزم:
1. لا تصادم نصوص ولا رموز خارج اليابسة.
2. حركة كاميرا مستمرة، والمسار لا ينفصل عن الخريطة.
3. مقارنة شكلية مع المرجع: توازن، وضوح، توظيف العناصر، لا مجرد grain.
4. مراجعة المستخدم؛ لا نكتب «احترافي تماماً» أو «نفس المرجع» بقرار آلي.
