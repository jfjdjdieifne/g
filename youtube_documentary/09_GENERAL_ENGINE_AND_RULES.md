# 09 · محرك المونتاج العام (board_engine v4) — لأي فيديو، أي موضوع

> هذا الملف يشرح النظام الجديد: **المشهد يُوصَف في ملف إعداد (JSON)، والمحرك يبني الفيديو.**
> مو مشروع إسكوبار — إسكوبار كان مجرد أول تطبيق. نفس المحرك يعمل على أي شخص/حدث/فكرة.

## الفكرة

```
config/sceneXX.json   →   tools/engines/board_engine.html   →   frames   →   MP4
   (الوصف)                    (المحرك العام)                   (إطارات)      (فيديو)
```

- **الوصف** فيه: صورة الموضوع، صورة السيلويت، مساحة اللوح، أماكن الكروت الفارغة، والنصوص، والتوقيتات.
- **المحرك** ثابت — ما يتغير بين موضوع وموضوع. تنبني مرة، تُستخدم دائماً.
- لتغيير الموضوع: انسخ ملف JSON، بدّل الصور والنصوص والتوقيتات. خلص.

## قواعد الإخراج (تصير افتراضية لكل فيديو)

1. **لا سلايدات، لا بطاقات، لا قوالب.** اللوح أكبر من الكادر والكاميرا تسافر فيه.
2. **لا كابشنات محروقة ولا SRT.** كل النص **مونتاج**: يُكتب، يُرسم، يُختم، وينشال بعد ما ينطق.
3. **لا موسيقى.** SFX سينمائية فقط: قلم على ورق، swoosh، هبوط، ريفيرب.
4. **لا وسوم ولا مصادر ولا "أرشيف" على الشاشة.** المصادر تُسجَّل في ملف الحقوق — مو على الفيديو. (استثناء: إذا طلب المستخدم وسم إلزامي).
5. **لا كتابات جاهزة فوق الصور.** الكروت تبقى بصرية صافية.
6. **السيلويت يُبنى من صورة الموضوع نفسها** — مو من شخص آخر، ومو كتلة سوداء: ظل داكن + خط نور خفيف يرسم ملامحه.
7. **كل اسم يُكتب** بخط اليد + (اختياري) **التوقيع الحقيقي** إذا توفّر كأصل مرخص.

## بنية الإعداد (JSON)

| الحقل | الوظيفة |
|---|---|
| `hero.x/y/w/h` | مكان وبُعد الكارت الرئيسي على اللوح |
| `hero.photoInset` | الهوامش (فيها يُكتب الاسم والتوقيع) |
| `slots[]` | الكروت الفارغة (ليها مشهدها، بلا أي كتابة) |
| `text.top / name / line / why / date` | النصوص المونتاجية |
| `hero_img / sil_img / rim_img / signature` | الصور: الأصلية، السيلويت، خط النور، التوقيع |
| `timing.*` | توقيتات كل حركة (ثوانٍ) |
| `timing.dur` | مدة المشهد الكلية |

## أدوات مساعدة

- `tools/prep_hero_asset.py` — يبني `hero_solo_cc0.jpg` + `hero_silhouette_dark.png` + `hero_rim.png` من صورة الموضوع (يحتاج إحداثيات كروب).
- `tools/synth_sfx_cine.py` — صوت سينمائي (ADSR + طبقات نغمية + ريفيرب Schroeder + ضغط ناعم). **قياس النقر: 3.6% FS** (الحد الآمن < 30%).
- `tools/render_engine.py` — يحوّل الإعداد لإطارات عبر Chromium + يتحقق من وجود كل الأصول.

## أمر واحد كامل

```bash
python3 tools/synth_sfx_cine.py mix.wav 10.0
python3 tools/render_engine.py config/escobar_scene01.json frames
ffmpeg -framerate 30 -i frames/f%04d.png -i mix.wav -c:v libx264 -crf 16 \
       -pix_fmt yuv420p -c:a aac -shortest out.mp4
```

## حالة القواعد مقابل البروفايل القديم

| قاعدة قديمة (v1) | القاعدة الجديدة |
|---|---|
| وسم "أرشيف/حديث/AI" على كل مادة | ❌ انشال — الحقوق في السجل، والشاشة نظيفة |
| كابشن محروق + SRT | ❌ انشال — النص كله مونتاج |
| موسيقى خلفية | ❌ انشال |
| صور مصغّرة توضيحية (تمبلت/IMG) | ❌ انشالت |
| زووم ثابت | ✅ صار travel كاميرا + ghost transform + متن مرسوم |

**ملاحظات تبقى سارية**: الحقوق تُتحقق قبل الاستخدام · لا مواد متنازع عليها · لا تكرار صورة · الأدوات مجانية فقط.
