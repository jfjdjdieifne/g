# Agent entry point

Before any project work, read **START_HERE.md at the repository root**, then its current authority files. Run `python3 studio/tools/projectctl.py doctor` and `brief` from the root. Do not begin from a historical HANDOFF or the last film.

Current task/status live only in `studio/CURRENT_STATE.json`; user rules in `studio/USER_RULES.md`; approval scope in `studio/REFERENCE_INDEX.json`. Connecting apps does not authorize a new film or establish user approval. Follow the task-specific onboarding and encoded-scene review workflow in `studio/OPERATIONS.md` before production.

Respect the environment's permitted session branch. The published source branch is identified in PROJECT.json, but that is not permission to switch to a forbidden branch or overwrite local work. Preserve unrelated root files and historical outputs. No credentials or large generated/media files in Git.
